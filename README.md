# 1789 — 한 프랑스인의 일생

1750~1790년 사이 프랑스에서 태어난 한 사람의 생을 살아 보는 브라우저 인생 시뮬레이션입니다. 1789년 전에는 계절 단위, 혁명이 시작되는 1789년부터는 한 달 단위로 진행됩니다.
구체제, 프랑스 혁명, 공포정치, 나폴레옹 제국, 왕정복고까지 실제 연표의 사건이 그 해 그 계절에 일어나고,
신분·거주지·성별·신앙·정치 성향에 따라 다르게 닥칩니다.

화면 구성은 「80억분의 1」, 진행 방식은 「승경도」, 파벌 카드와 강령 표현은 「Bonaparte – A Mechanized Revolution」을 참고했습니다.

## 실행과 배포

배포용 파일은 `docs/index.html` 하나입니다(빌드 결과물을 커밋합니다). 로컬에서는 이 파일을 브라우저로 바로 열면 됩니다.

GitHub Pages 설정 (한 번만):

1. 이 브랜치를 `main`에 병합합니다.
2. 저장소 **Settings → Pages → Build and deployment**에서 Source를 **Deploy from a branch**로, Branch를 **`main`** / 폴더 **`/docs`**로 지정하고 저장합니다.
3. 잠시 뒤 `https://<사용자명>.github.io/<저장소명>/`에서 열립니다.

`docs/.nojekyll`이 있어 Jekyll 처리 없이 파일이 그대로 서비스됩니다.

## 구조

| 파일 | 내용 |
| --- | --- |
| `src/index.template.html` | 마크업 |
| `src/style.css` | 스타일 (시대에 따라 바뀌는 `--era` 색) |
| `src/core.js` | 신분·지역·이름·시대·곡물가·사망률 표 |
| `src/life.js` | 상태 도우미, 직업 사다리, 기록, 주사위·확률 판정 |
| `src/engine.js` | 계절 진행, 경제, 가족, 승진, 공포정치, 전쟁·징집, 망명 |
| `src/history.js` | 1751~1851년 연표 사건 |
| `src/events.js` | 무작위 사건과 행동 |
| `src/stories.js` | 실존 인물과의 만남, 널리 알려진 일화, 지방 풍속, 연표 보강 |
| `src/politics.js` | 시기별 실제 파벌, 강령(쟁점 7개), 정치 성향 점수, 당 활동, 파벌 숙청 |
| `src/scene.js` | 장면 구성: 장소 판단, 가족 목록, 캡션 |
| `src/art/` | 픽셀 아트: 공통 하늘·땅·깃발(`common.js`), 도시·항구(`city.js`), 마을·성관·숲(`country.js`), 감옥·야영지·성당·망명지(`places.js`), 시대 복식 인물(`people.js`) |
| `src/ui.js` | 화면, 사건 창, 저장, 부고 |

수정 후 `npm run build`(또는 `node build.mjs`)로 `docs/index.html`을 다시 만들고 함께 커밋합니다. `dist/artifact.html`은 Claude 아티팩트 게시용 조각으로, 저장소에는 올리지 않습니다.

## 확률의 근거 (단순화)

- 사망률: 18세기 프랑스 생명표(INED, Louis Henry) — 영아사망률 약 21~25%
- 신분 비율: 귀족 약 1.5%, 농민 약 4분의 3
- 공포정치: 투옥 약 50만 명, 공식 처형 약 1만 7천 명(Greer, 1935)
- 9월 학살: 수감자 약 2,700명 중 1,100~1,400명 사망
- 징집: 1793년 국민총동원, 1798년 주르당 법, 제정기 연도별 소집 비율
- 전쟁: 연도별 병사 사망률, 러시아 원정(보로디노·퇴각·베레지나) 손실
